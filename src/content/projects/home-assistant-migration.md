Transitioning my smart home ecosystem from Google Home to Home Assistant Supervisor, including device migration, automation rebuilds, and stability improvements.

## Overview

This project focuses on replacing Google Home with a fully local, stable, and extensible Home Assistant Supervisor deployment. The migration includes device onboarding, automation recreation, and long-term reliability work.

## Technical Details

- **Deployment:** Supervisor-based deployment on dedicated hardware
- **Ecosystem:** Local add-on ecosystem and MQTT integration
- **Strategy:** Phased device migration strategy
- **Automations:** Rebuilding cloud-dependent routines into resilient local automations
- **Reliability:** Stability and uptime improvements with automated backup verification

## Status

Migration in progress. Core devices onboarded; automation rebuild underway.
